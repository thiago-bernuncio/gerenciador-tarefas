# Gerenciador de Tarefas


## Aplicação para organizar tarefsd pessoais, estudos e projetos.

tecnologias utilizadas
 - React
 - Node.js
 - Express
 - SQL

Funcionalidades planejadas 
 - Cadastro e login de usuário
 - Criar, editar, conluir e excluir tarefas
 - Definir propriedades, categoria e prazo
 - Filtrar tarefas pos status
 - Interfaze responsiva
 - Persistencia dos dados em banco SQL
